# Misión

## Que construimos

**VittaSelf** es un sistema ERP ligero, para una plataforma de ventas multinivel donde los empresarios (euis) hacen parte de la red de distribución, compran productos del catalogo o mediante ventas internas realizadas por asesores. La compra de productos o sumar empresarios a su red les permite ascender en los **planes** y conseguir **beneficios**.

La pagina cuenta con
1. **Sidebar**: Navegador principal para dirigirse a las paginas.
2. **Header**: Para gestionar el perfil, el carrito de compras y preferencias.
3. **Footer**: Nombre del desarrollador, año y derechos de autor.
4. **Content:** Pagina que muestra el contenido principal segun lo que el usuario seleccione en el sidebar o por URL.

## Para quien
- Empleados de VittaSelf quienes realizan gestion interna
- Empresarios de VittaSelf quienes compran productos

## Que no es
- **No es un CRM**: Si bien se gestionan clientes, se persive mas como un ERP ya que principalmente se manejan recursos internos.
- **No es una landing page**: Aunque se realizan ventas, los empresarios son parte de la red de distribucion de VittaSelf.
