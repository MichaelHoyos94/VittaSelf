# Feature 034: Mejorar el estilo visual del background de contenido

## Objetivo
Generar un background fijo agradable en la seccion principal de contenido donde se muestran las diferentes paginas como auditorias, dashboard, gestion de productos, catalogo entre otros.

## Alcance
- Mejorar el estilo visual del background

## Fuera de alcance
- No se debe modificar logica de negocio
- No modificar textos ni estilos fuera de el background
- No tocar los demas componentes del layout. Header, Sidebar ni footer

## Regla
- Con tailwind y/o modificacion del archivo css. No css inline

## Criterios de aceptacion
- El background tiene una apariencia mas agradable
- No tiene CSS inline
- No se modifica logica de negocio
- No se tocan otros componentes del dashboard ni paginas
