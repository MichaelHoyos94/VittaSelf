# 027 . Sistema multinivel para empresarios — Spec

**Estado**: Pendiente 🏗️

## Que hace

Sistema o estructura de representantes y representados multinivel.

## Por qué

El core de negocio lo exige. Los empresarios generar ganancias con las ordenes de los empresarios que tienen en su red de representados, y para ello debe estar la estructura.

## Criterios de aceptación

- [ ] El formulario incluye el buscador para el representante.
- [ ] Se pueden crear empresarios sin un empresario representante.
- [ ] Si busco empresario por `eui_code` y esta sancionado o inactivo, se muestra una alerta informativo.
- [ ] Si busco empresario por `eui_code` y es apto, se previsualiza la informacion.
- [ ] Permite registrar un empresario con su empresario representante.
- [ ] Un empresario, puede tener multiples empresarios representados.
